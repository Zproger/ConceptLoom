# Concept Loom

**Превратите вашего AI-помощника для кода в учебного тренера, который помнит, что вы уже знаете.**

Работает с Codex, Claude Code, OpenCode и DeepSeek Harness · Лицензия MIT · Node.js 20+

[Русский](#concept-loom) · [English](../../README.md)

Вместо длинной лекции Concept Loom находит границу вашего понимания, предлагает короткий путь к цели, объясняет по одной идее и проверяет, что она усвоена. Он помнит ваш прогресс между сессиями и между проектами.

```text
цель → что вы уже знаете → короткий маршрут → одна идея → проверка → повторение позже
```

Подход работает для новых тем и для ваших книг, курсов, заметок, кода и транскриптов.

## Что вы получаете

| | |
|---|---|
| **Маршрут, а не лекция** | Короткий путь к вашей цели вместо обзора всей области. |
| **Честные проверки** | Вопросы со скрытым ответом. Узнавание, воспроизведение, применение и перенос оцениваются отдельно. |
| **Память между сессиями** | Закрыли чат — завтра продолжите с того же шага. Нужные понятия возвращаются на интервальное повторение. |
| **Память между проектами** | Учили Docker в прошлом месяце? Когда вы начнёте Kubernetes, тренер опирается на это. Старое знание проверяется быстрым вопросом, а не принимается на веру. |
| **Долгосрочные цели** | Большую цель («писать backend на Go») можно разбить на этапы. Каждый этап — отдельное сфокусированное занятие, а тренер сам выбирает, что делать дальше. |
| **Конспекты и схемы** | Markdown-конспект и текстовые или Mermaid-схемы прямо в разговоре. |

## Быстрый старт

Нужны [Node.js 20+](https://nodejs.org) и один из поддерживаемых AI-клиентов.

### 1. Установите в учебную папку

Сделайте отдельную папку под каждую тему и установите в неё Concept Loom. Команду запускайте из репозитория Concept Loom:

```bash
node scripts/setup.mjs <клиент> --target ~/learning/моя-тема
```

Вместо `<клиент>` подставьте ваш инструмент:

| Вы используете | Вместо `<клиент>` | Чем запускать |
|---|---|---|
| Codex | `codex` | `codex` |
| Claude Code | `claude-code` | `claude` |
| OpenCode | `opencode` | `opencode` |
| DeepSeek Harness | `deepseek-harness` | `npx @deepseek-ai/dsh --profile web --patch .dsh/concept-loom.patch.yml` |

### 2. Запустите клиент в этой папке

```bash
cd ~/learning/моя-тема
claude        # или команда запуска из таблицы выше
```

### 3. Скажите, что хотите изучить

```text
Используй concept-coach. Я хочу понять транзакции в базах данных настолько,
чтобы выбирать подходящий уровень изоляции для небольшого веб-приложения.
```

В Codex пишите `$concept-coach` вместо `concept-coach`.

Это всё. Тренер задаст несколько вопросов, покажет маршрут, дождётся вашего одобрения и начнёт объяснять.

## Как пользоваться каждый день

Просто разговаривайте. Учить дополнительные команды не нужно.

| Вы говорите | Что происходит |
|---|---|
| «Продолжим» | Восстанавливается последнее занятие или следующий этап цели, и вы продолжаете с места остановки. |
| «Это большая тема, сделай цель с этапами» | Предлагаются этапы по порядку, после вашего одобрения они сохраняются, и за занятие проходится один этап. |
| «Хочу изучить Kubernetes» | Тренер ищет то, что вы уже учили (например, Docker), и пропускает или сокращает известное. |
| «Я забыл, как работают volumes в Docker» | Понятие помечается для повторной проверки, прежде чем на нём что-то строить. |
| «Покажи, что ты обо мне знаешь» | Выводится вся карта знаний и степень свежести каждой записи. |
| «Импортируй мои прошлые сессии в карту знаний» | Разовый импорт сессий, уже сохранённых в этой папке. Выполните один раз в каждом старом проекте. |

## Где хранятся данные

| Что | Где |
|---|---|
| Занятия, цели и прогресс | `<папка-темы>/.concept-loom/` |
| Markdown-конспект | `<папка-темы>/learning-notes.md` |
| Карта знаний между проектами | `~/.concept-loom/knowledge.json` |

Всё остаётся на вашем компьютере, сам Concept Loom ничего никуда не отправляет. Чтобы перенести карту знаний, задайте переменную окружения `CONCEPT_LOOM_HOME` с другой папкой. Чтобы отключить её, задайте значение `off`.

Знание, которое не проверяли 90 дней, считается «требующим проверки», потому что память слабеет. Тренер перепроверяет его коротким вопросом, а не доверяет сразу.

## Обновление

Скачайте новую версию Concept Loom и обновите навык в каждой учебной папке:

```bash
node scripts/setup.mjs <клиент> --target ~/learning/моя-тема --refresh
```

`--refresh` заменяет навык тренера (а для DeepSeek Harness ещё и MCP-патч) и не трогает ваши конспекты, занятия и остальную конфигурацию. Делайте это после каждого обновления, чтобы тренер узнал о новых возможностях.

## Что полезно знать

- Установщик никогда не перезаписывает существующую конфигурацию. Если `CLAUDE.md`, `AGENTS.md` или MCP-конфиг уже есть, он создаёт отдельный файл `CONCEPT_LOOM_*.md`, который нужно объединить вручную.
- `--skip-mcp` устанавливает только файлы и не меняет глобальную конфигурацию клиента.
- Codex регистрирует MCP-сервер глобально, остальные клиенты хранят его в учебной папке.
- DeepSeek Harness находится в developer preview, поэтому формат его конфигурации может меняться.
- У Concept Loom нет runtime-зависимостей npm.
