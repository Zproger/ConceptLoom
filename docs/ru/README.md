# Concept Loom

**Переносимый AI-подход к обучению для Codex, Claude Code, OpenCode и DeepSeek Harness.**

[Русский](#concept-loom) · [English](../../README.md)

Concept Loom превращает coding-агента в структурированного учебного партнёра. Вместо немедленной длинной лекции AI помогает определить полезную цель, найти границу понимания, предложить короткий маршрут зависимостей и проходить по одной связи за раз.

```text
цель → граница знаний → карта → одна связь → проверка → перенос
```

Подход работает для совершенно новых тем и для ваших книг, курсов, заметок, кода и транскриптов.

## Зачем это нужно

- Учиться ради практического результата, а не обзора всей дисциплины.
- Находить пробелы и заблуждения до построения следующих идей.
- Проверять понимание вопросами со скрытым ответом.
- Сохранять компактный Markdown-конспект между сессиями.
- Использовать один подход в четырёх поддерживаемых клиентах.

## Быстрый запуск с Codex

Нужны Node.js 20+ и Codex CLI.

```bash
node scripts/setup.mjs codex --target /путь/к/учебной-папке
cd /путь/к/учебной-папке
codex
```

Установщик сам вычисляет путь и регистрирует MCP-сервер в Codex. Флаг `--skip-mcp` позволяет установить только файлы workspace, не меняя глобальную MCP-конфигурацию.

После обновления Concept Loom обновите уже установленный skill командой `node scripts/setup.mjs codex --target /путь/к/учебной-папке --refresh`.

Первый запрос:

```text
Используй $concept-coach. Я хочу понять транзакции в базах данных настолько,
чтобы выбирать подходящий уровень изоляции для небольшого веб-приложения.
```

## Другие клиенты

```bash
node scripts/setup.mjs claude-code --target /путь/к/учебной-папке
node scripts/setup.mjs opencode --target /путь/к/учебной-папке
node scripts/setup.mjs deepseek-harness --target /путь/к/учебной-папке
```

Для DeepSeek Harness установщик создаёт нативный project skill и отдельный MCP patch. Запускайте Harness из учебной папки так:

```bash
npx @deepseek-ai/dsh --profile web --patch .dsh/concept-loom.patch.yml
```

DeepSeek Harness пока находится в developer preview, поэтому его формат конфигурации может меняться. Флаг `--skip-mcp` устанавливает только `.dsh/skills/concept-coach`, если MCP-сервер вы подключаете через собственный профиль Harness.

Установщик не перезаписывает существующую конфигурацию. При конфликте вручную объедините её со сгенерированным файлом Concept Loom.

У Concept Loom нет runtime-зависимостей npm. Небольшие структуры показываются текстовыми схемами прямо в терминале, а более крупные карты — блоками Mermaid, которые также можно сохранить в Markdown-конспект.
