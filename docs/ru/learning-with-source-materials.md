# Изучение книг, курсов и файлов с AI

[Документация](README.md) · [English](../en/learning-with-source-materials.md)

Источник задаёт содержание, а Concept Loom помогает видеть связи, практиковаться и проверять понимание. Не заменяйте чтение полным AI-пересказом. Используйте только материалы, к которым у вас есть законный доступ.

## 1. Организуйте папку

```text
learning-workspace/
├── originals/    неизменённые исходники
├── prepared/     текст для поиска и индекс
├── notebook/     цель, маршрут и состояние знаний
├── exercises/
└── projects/
```

## 2. Подготовьте форматы

### PDF

```bash
pdfinfo "originals/book.pdf"
pdftotext -layout "originals/book.pdf" "prepared/book.txt"
pdftotext -f 25 -l 48 "originals/book.pdf" "prepared/chapter-02.txt"
```

Пустой или испорченный текст может означать, что нужен OCR. Важные формулы, таблицы, отрицания и страницы проверяйте по оригиналу.

### EPUB

```bash
mkdir -p prepared/epub
unzip -q "originals/book.epub" -d prepared/epub
```

Попросите AI определять порядок глав по manifest и spine, а не по алфавиту файлов. Сохраняйте заголовки, сноски, подписи, формулы и таблицы.

### Markdown, TXT, HTML, DOCX и RTF

Markdown, TXT и HTML уже доступны для поиска. Храните один смысловой раздел в одном файле. В macOS DOCX или RTF можно извлечь так:

```bash
textutil -convert txt -output "prepared/document.txt" "originals/document.docx"
```

Сложные формулы и таблицы сравнивайте с оригиналом.

### Видео и аудио

Используйте субтитры, транскрипт, заметки или доверенный инструмент распознавания. Сохраняйте таймкоды. Извлечение аудио:

```bash
ffmpeg -i "originals/lesson.mp4" -vn -ac 1 -ar 16000 "prepared/lesson.wav"
```

Это не транскрипция. Слайды экспортируйте в PDF, а код и notebooks оставляйте в исходной структуре.

## 3. Создайте индекс вместо огромного запроса

```text
Изучи prepared/ для навигации. Создай prepared/index.md: название каждого
раздела, путь, понятия, предварительные знания и место в источнике. Не пересказывай
всё произведение и не начинай обучение.
```

Сохраняйте границы глав и разрешайте AI читать нужные файлы выборочно.

## 4. Персонализируйте порядок

```text
Используй $concept-coach. Моя практическая цель — [РЕЗУЛЬТАТ]. Прочитай индекс
и проверь нужные разделы. Раздели материал на обязательный, предварительный и
необязательный; диагностируй мои знания; предложи маршрут и дождись одобрения.
```

## 5. Цикл до, во время и после

- **До:** спросите, зачем нужен раздел и какие ответы искать, без готового пересказа.
- **Во время:** укажите файл, страницу, раздел или таймкод и попросите найти первую недостающую предпосылку.
- **После:** по памяти объясните проблему автора, предпосылки, вывод и ограничения; затем исправляйте по одному расхождению и применяйте идею в новой задаче.

## 6. Отделяйте автора от актуальных данных

```text
Раздели анализ на Source view — позиция автора с местом в источнике — и Evidence
view — подтверждается ли она современными первичными или официальными данными.
Покажи разногласия и устаревшие допущения явно.
```

## 7. Защитите упражнения

```text
Не читай и не показывай решение до моей попытки. Сначала попроси сформулировать
цель, известные данные и связь с картой. Давай минимальные подсказки. После решения
дай новую задачу с другим сюжетом, проверяющую ту же связь.
```

## 8. Записывайте доказательства

```text
secure         восстановлено и применено в новой задаче
fragile        узнаётся, но ненадёжно используется
missing        ещё не построено
misconception  обнаружена неправильная модель
```

В конце обновляйте `notebook/knowledge-state.md`: место в источнике, доказательство понимания, оставшуюся слабость и следующую точку повторения.

## Стартовый запрос

```text
Используй $concept-coach.

Я изучаю [КНИГА ИЛИ КУРС]. Оригиналы находятся в originals/, текст для поиска —
в prepared/. Моя цель — [РЕЗУЛЬТАТ]. Создай или проверь индекс, отдели утверждения
источника от требующих проверки, диагностируй знания и предложи персональный
маршрут. Дождись одобрения. Требуй мою попытку до помощи, проверяй по одной связи,
давай задачи на перенос, сохраняй ссылки и обновляй notebook/. Не меняй originals/.
```
