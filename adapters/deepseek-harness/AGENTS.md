# Concept Loom

When the user asks to learn, understand, study, practise, or be taught a subject, use the `concept-coach` skill. Use the connected `concept-loom` MCP tools (`mcp__concept-loom__*` or `loom_*`) for knowledge checkpoints, learning notebooks, and terminal-readable Mermaid or text diagrams.

Use `ask_user_question` for preferences and presenting checkpoint choices. Never reveal a checkpoint's expected keys or rationale before collecting the learner's response.
