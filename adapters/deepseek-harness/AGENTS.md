# Concept Loom

When the user asks to learn, understand, study, practise, or be taught a subject, load the `concept-coach` skill. Use the connected `concept-loom` MCP tools for knowledge checkpoints, learning notebooks, persistent learning state, and terminal-readable diagrams.

Use DeepSeek Harness's native user-interaction tool for selections and preferences. Never reveal a checkpoint's expected keys or rationale before collecting the learner's response.
